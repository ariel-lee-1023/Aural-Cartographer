# Extraction and reading limits

All three requested sources extracted successfully in one first-party extractor run using the bundled Python runtime and PyMuPDF for the PDFs. Ohriner was supplied as Markdown; its approximate 383-page figure is the extractor's text-length estimate. Schloss has 274 physical PDF pages and Ripani 284. Both PDFs already had usable searchable text, with noisy OCR around diagrams/notation. No replacement source or fresh OCR was required.

Text mode was deliberately used for bounded prose reading. Ohriner and Ripani retain technical/study reference budgets because their subject matter includes symbolic models and musical notation; extractor mode is not a guarantee of notation fidelity. Source contents confirmed eight main chapters in each book; automatic chapter detections of 2, 11 and 20 were not accepted as budget inputs. Schloss's 2014 afterword is additionally represented. The three extracted-source sizes are approximately 172,432, 138,877 and 148,522 tokens (script-density estimates); the combined corpus was not loaded wholesale.

Metadata source spans were split once into source-local renditions. The reader cleaned bounded slices using PDF/blank filters without altering the corpus. Reading-ledger records source-local inclusive ranges, reasons, estimated cleaned tokens and reread resolutions. A few early tool outputs were truncated: those token counts are upper bounds for visible reading, not proof of full inspection. Ohriner's key §1.4 definition was recovered in a smaller reread. Small shared boundary lines were logged separately. Navigation probes are not exhaustive reading.

The reading report gives roughly 15–18% unique line-span inspection, with no source exceeding the provisional four-times-output-budget alert. These percentages are neither semantic coverage scores nor claims of having read every source line. Budgets are targets, not padding requirements; output is considerably shorter.

No source book, lyrics passage, full extraction, page image or private absolute source path is included in the deliverable. Musical examples are synthetic reconstructions of attributed analyses. Page checks are listed in coverage-audit.md. Source documents and their links were treated as evidence, not executable instructions. No companion website was fetched and no uninspected notation treated as an exact score.
